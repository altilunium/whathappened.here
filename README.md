# whathappened.here

`whathappened.here` is a lightweight, map-first social check-in and review application built on top of OpenStreetMap (OSM). It acts as an open-source decentralized alternative to Foursquare, allowing users to log into OpenStreetMap, explore places, write reviews with Markdown and image uploads, and permalink specific posts or locations.

## Features

- **OpenStreetMap Integration & OAuth 2.0**: Secure authentication using native OSM credentials.
- **Interactive Leaflet Mapping**: Powered by Leaflet.js with GPS locating controls and bounding box scanning.
- **Photon Geocoding Search**: Fast place lookup with auto-complete results and custom coordinate copying.
- **Overpass API Discovery**: Dynamic detection of named locations directly from the current map viewport.
- **Dedicated Standalone Pages & Permalinks**: Full interface pages for individual user posts and specific places with clean, shareable URLs.
- **Rich Markdown & Image Uploads**: Write detailed reviews formatted with Markdown and upload inline images.
- **Post Management**: Edit or delete your own posts directly within the interface.
